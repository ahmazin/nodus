# Stencils & Templates — Implementation Plan

> Executes `docs/superpowers/specs/2026-07-19-stencils-design.md`. Wave-based (dependency-ordered):
> Wave 1 (core primitives + package, parallel) → Wave 2 (React panels) → Wave 3 (example wiring).
> Steps use TDD. The lead verifies + commits at each wave.

**Goal:** Reusable element-group **stencils** (save selection → library panel → drag to place) + a **templates** gallery (open a full starting diagram), with a git-diffable canonical format.

**Key reuse:** the primitives wrap existing `Editor` internals — `collectForCopy(ids)` (nodes + descendants + interconnecting edges, `editor/index.ts:806`) and `pasteRecords(records, offset)` (fresh ids + endpoint remap + offset + one-undo apply, `editor/index.ts:844`). Serialization reuses `stableStringify` from `@ahmazin/core`.

## Global Constraints

- Canonical/deterministic output for `.noduslib.json` (sorted keys via `stableStringify`) — libraries must diff cleanly.
- A placed stencil is a **plain copy** (fresh ids, no master link). No components/symbols in v1.
- Static gate `pnpm typecheck`; tests `pnpm exec vitest run <file>` (node env, no DOM — React panels are browser-verified, not unit-tested).
- Route mutations through `store.apply`/editor helpers; placement is ONE undo entry.

## Wave 1 — foundation (two parallel, file-disjoint lanes)

### Task A: core `captureStencil` + `placeStencil` primitives
**Files:** `packages/core/src/editor/index.ts`; `packages/core/src/index.ts` (export any new types); `packages/core/src/editor/stencil.test.ts` (new).
**Produces (contract):**
```ts
// on Editor:
captureStencil(ids: Id[]): NodusRecord[];        // a normalized, placement-agnostic fragment
placeStencil(records: NodusRecord[], at: Vec2): Id[];  // clones into the doc at `at`, one undo, returns new ids
```
**Implementation:**
- `captureStencil(ids)`: start from `this.collectForCopy(ids)` (already gathers nodes + descendants + internal edges, dropping edges to unselected nodes). Then NORMALIZE for a stable, placement-agnostic fragment: (1) build an `old→new` id map assigning `node:n0, node:n1, …` and `edge:e0, …` **in a deterministic order** (sort the collected records by current id first, so the mapping is reproducible); (2) rewrite each record's `id`, plus `edge.from.nodeId`/`edge.to.nodeId` (when `kind` is `node`/`outline`) and `node.parentId`, through the map (drop a `parentId` that isn't in the map); (3) compute the node bounding-box min (x,y) and subtract it from every node's `x,y` so the fragment origin is `(0,0)`. Return the new record array (do NOT apply — this is data). Reuse a shared private `remapRecordIds(records, makeIdFor)` helper so capture and `pasteRecords` share the endpoint/parent-rewrite logic (extract it from `pasteRecords` if not already separate — DRY).
- `placeStencil(records, at)`: delegate to the existing `pasteRecords(records, at)` (fresh ids via `makeId`, endpoint/parent remap, offset each position by `at`, `store.apply` as one undo, select + return new ids). Since a captured fragment's origin is `(0,0)`, offsetting by `at` lands it at `at`. If `pasteRecords` is private, `placeStencil` is the public wrapper.
**Tests (`stencil.test.ts`, TDD):**
1. Capture 2 nodes + 1 edge connecting them → returned records have normalized ids (`node:n0`,`node:n1`,`edge:e0`), the edge's `from/to.nodeId` point at the normalized node ids, and node positions are bbox-relative (min corner at 0,0). Fails before the method exists.
2. Capture a selection that includes an edge to an **unselected** node → that edge is dropped (0 dangling refs in the fragment).
3. `placeStencil(fragment, {x:200,y:120})` → new records exist in the store with **fresh ids** (none equal to the fragment's `n0/e0` or to pre-existing ids), edge refs rewritten to the new node ids, positions offset by `(200,120)`; a single `undo()` removes all of them.
4. Round-trip: capture → place → the placed subgraph is structurally identical (same shape/edges) to the original selection, at the new location.
**Verify:** `pnpm typecheck`; `pnpm exec vitest run packages/core/src/editor/stencil.test.ts`.

### Task B: `@ahmazin/stencils` package — types, canonical serialize, built-in content
**Files (new package):** `packages/stencils/package.json`, `tsconfig.json`, `tsup.config.ts` (mirror another leaf package like `@ahmazin/layout-tree` for config), `src/index.ts`, `src/types.ts`, `src/serialize.ts`, `src/builtin.ts`, `src/serialize.test.ts`, `README.md`, `LICENSE`.
> The package depends ONLY on `@ahmazin/core` (`workspace:*`). The lead adds it to the workspace + installs; the implementer must NOT run `pnpm install` — if resolution needs it, report to the lead.
**Produces (contract):**
```ts
export interface Stencil { id: string; name: string; tags?: string[]; records: NodusRecord[]; preview?: string; }
export interface StencilLibrary { name: string; stencils: Stencil[]; }
export interface Template { id: string; name: string; description?: string; snapshot: Snapshot; preview?: string; }
export function serializeLibrary(lib: StencilLibrary): string;   // canonical: stableStringify(lib) + trailing "\n"
export function parseLibrary(json: string): StencilLibrary;      // JSON.parse + shape-guard (drop malformed stencils)
export const builtinStencils: StencilLibrary;                    // small starter set
export const builtinTemplates: Template[];                       // 2–3 starting diagrams
```
**Implementation:**
- `types.ts`: the interfaces above (import `NodusRecord`, `Snapshot` from `@ahmazin/core`).
- `serialize.ts`: `serializeLibrary` = `stableStringify(lib) + '\n'` (import `stableStringify` from `@ahmazin/core`) so libraries are canonical/diff-stable; `parseLibrary` = `JSON.parse` then validate (`name` string, `stencils` array; each stencil has string `id`/`name` and array `records` — drop entries that don't).
- `builtin.ts`: 3–4 stencils authored as canonical fragments (each a plain box/note/decision-diamond built from the core `rect`/draw types — a couple of `NodusRecord` nodes with `x,y` origin at 0,0) and 2–3 `Template`s whose `snapshot` is a valid `{ schemaVersion: 1, document: { records } }` (a blank, a small "3-tier web app", a "CI/CD pipeline"). Keep records minimal and valid (ids unique within each fragment/snapshot).
**Tests (`serialize.test.ts`, TDD):**
1. `serializeLibrary` output is byte-stable across two calls and has sorted keys (assert a known small library serializes to an exact expected string).
2. `parseLibrary(serializeLibrary(lib))` deep-equals `lib`.
3. `parseLibrary` drops a malformed stencil (e.g. missing `records`) without throwing.
4. Every `builtinStencils.stencils[*].records` and `builtinTemplates[*].snapshot` restores cleanly via core `restore()` (0 dropped edges, non-empty).
**Verify:** `pnpm typecheck`; `pnpm exec vitest run packages/stencils`.

## Wave 2 — React panels (dispatched after Wave 1 verified; uses Task A methods + Task B types)

### Task C: `<StencilLibrary>` + `<TemplatesGallery>` panels
**Files:** `packages/react/src/stencil-library.tsx` (new), `packages/react/src/templates-gallery.tsx` (new), `packages/react/src/index.tsx` (export both).
**Read first:** `packages/react/src/cloud-icon-picker.tsx` (the pattern to generalize: search, provider chips/groups, recents, drag-to-canvas via the canvas-registry), and how it places a node on drop.
**Implementation:**
- `<StencilLibrary editor libraries onSaveSelection?>`: a searchable panel of stencil previews grouped by library, a recents strip, drag-to-canvas that calls `editor.placeStencil(stencil.records, dropWorldPoint)` (reuse the CloudIconPicker drag→canvas-registry→world-point path), and a "Save selection as stencil" button that prompts for a name, calls `editor.captureStencil(editor.selectedIdsArray())`, wraps it as a `Stencil`, and invokes `onSaveSelection(stencil)`. Previews: render each stencil's records to a small SVG thumbnail on demand via `renderSVG` (build a throwaway `Editor`, `placeStencil`, `renderSVG`) or an inline mini-canvas — pick the simpler; cache by stencil id.
- `<TemplatesGallery editor templates onBeforeOpen?>`: a grid of template previews; clicking calls (optionally `await onBeforeOpen()` for an unsaved-changes guard, then) `editor.loadSnapshot(template.snapshot, { fit: true })`.
**Verify:** `pnpm typecheck`. React DOM → browser-verified by the lead (drag-to-place, save-from-selection, open-template), not unit-tested.
