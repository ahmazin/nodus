vendored the toolkit into `packages/icons-cloud/svg/gcp/`). That artwork is not owned by, or

- Toolkit download: https://cloud.google.com/icons

This file intentionally does **not** paste Google's license/terms text: that text belongs to
Google, changes over time, and must be read at the source to be current. Before downloading,
vendoring, converting, or distributing anything derived from this toolkit you must:

1. Visit the toolkit page above yourself.
2. Read and accept Google's current terms for these icons.
3. Confirm your intended use (including any redistribution via this repository or its build
