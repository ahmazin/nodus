into vector icon packs used by this project (via `pnpm build:icons`, once you have vendored the
toolkit into `packages/icons-cloud/svg/aws/`). That artwork is not owned by, or licensed under

- Toolkit download: https://aws.amazon.com/architecture/icons/
- The toolkit page links to Amazon's current usage guidelines for these icons (redistribution,
  modification, and attribution rules, and restrictions on implying AWS endorsement).

This file intentionally does **not** paste AWS's license/usage-guideline text: that text belongs
to Amazon, changes over time, and must be read at the source to be current. Before downloading,
vendoring, converting, or distributing anything derived from this toolkit you must:

1. Visit the toolkit page above yourself.
2. Read and accept AWS's current terms for these icons.
3. Confirm your intended use (including any redistribution via this repository or its build
