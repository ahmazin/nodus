The moat

Diagrams that review like code.

Every scene serializes to a canonical, deterministic .nodus.json. Same diagram, byte-identical output — so version control does what it does best: line-by-line diffs, blame, review, merge.

  • Code-reviewable in a PR. Reviewers see exactly which nodes and edges changed.
  • A real CLI. nodus fmt / render / diff plus a diagrams CI workflow.
  • Fault-isolated migrations. Custom-shape typeVersions restore safely.

The SDK

Install it. Extend anything.

Turnkey React hook, or drive the framework-agnostic core yourself. Type-specific behavior is registered data — node/edge types, routers, layouts, plugins — never a switch in the core.

01One mutation channel. Every change flows through store.apply — inverse deltas, history & the scene index stay atomic.
02Signals substrate. A tiny reactive engine — atom / computed / effect.
import { Nodus, useNodusEditor } from '@ahmazin/react'
import { infraPreset } from '@ahmazin/preset-infra'

export function Editor() {
  const editor = useNodusEditor({
    presets: [infraPreset],
    persistence: 'local',   // autosave → .nodus.json
  })
  return <Nodus editor={editor} className="h-screen" />
}
import { defineNodeUtil } from '@ahmazin/core'

// register a custom shape — no core changes
export const StickyNote = defineNodeUtil({
  type: 'sticky',
  typeVersion: 2,
  defaults: () => ({ w: 180, h: 180 }),
  render(ctx, node) {
    ctx.roundRect(node, 8)
    ctx.text(node.props.text, { pad: 12 })
  },
  migrations: { 2: (n) => ({ ...n, fill: n.color }) },
})
// every change is one transaction — inverse
// deltas are computed for undo, and the scene
// index + event bus stay in sync, atomically
store.apply(
  [move(node.id, { x: 330, y: 222 })],
  { capture: 'immediately' },  // undo grouping
)

store.undo()   // ← restores via recorded inverse
import { fromMermaid } from '@ahmazin/from-mermaid'

const scene = fromMermaid(`
  flowchart LR
    A[Client] --> B{Gateway}
    B --> C[(Postgres)]
`)

editor.load(scene)   // canonical, diff-clean on save
