# Maintainers

This file lists the people responsible for Nodus (`@nodus-dev/*`). The decision-making model and the
succession posture are described in [GOVERNANCE.md](./GOVERNANCE.md).

## Current maintainers

| Maintainer | GitHub | Areas |
| --- | --- | --- |
| Ali Malik | [@ahmazin](https://github.com/ahmazin) | Everything — engine, packages, releases, docs, site |

Nodus currently has **one maintainer**. This is a **bus factor of one**: a single person reviews and
merges every change and is the sole owner of the `@nodus-dev` npm organization and the GitHub
repository. We state this plainly so that adopters can make an informed dependency decision.

## Publishing rights

Releases are published to npm by the maintainer using an `@nodus-dev`-scoped token. There is currently
**no second npm-org owner**. Adding one is a tracked continuity action — see the succession section of
[GOVERNANCE.md](./GOVERNANCE.md#succession-and-continuity-bus-factor-mitigation).

## Adding maintainers

There is no formal committer track yet. When the project is ready to add maintainers, the criteria and
process will be defined in [GOVERNANCE.md](./GOVERNANCE.md) and new maintainers will be added to the
table above in the same pull request that grants their access.
