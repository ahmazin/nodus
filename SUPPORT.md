# Getting Support

Nodus (`@nodus-dev/*`) is an open-source project maintained by a single maintainer in their spare time.
Support is **best-effort** — there is no commercial SLA for general questions, and response times vary.
We appreciate your patience, and well-formed questions with a reproduction get help fastest.

Before opening anything, please check the [documentation](./docs/) and the package READMEs — they cover
setup, the extension axes, headless rendering, the React binding, the CLI, and the MCP server.

## Where to go

| I want to… | Use |
| --- | --- |
| Ask a question, share an idea, show what you built, or get help | [GitHub Discussions](https://github.com/ahmazin/nodus/discussions) |
| Report a reproducible bug | [GitHub Issues](https://github.com/ahmazin/nodus/issues) → **Bug report** |
| Request a feature or enhancement | [GitHub Issues](https://github.com/ahmazin/nodus/issues) → **Feature request** |
| Report a security vulnerability | **Do not open a public issue** — follow [SECURITY.md](./SECURITY.md) |

> GitHub Discussions is the front door for questions so that issues stay focused on tracked bugs and
> feature work. If you open an issue that is really a question, we may convert it to a Discussion.

## Filing a good bug report

The more of this you include, the faster we can help:

- The **package(s) and versions** affected (`@nodus-dev/core@0.3.0`, etc.) and your Node / browser /
  framework versions.
- A **minimal reproduction** — the smallest code snippet, `.nodus.json` document, or steps that
  triggers the problem.
- What you **expected** to happen and what **actually** happened, including any error text or stack.

## Security

Security vulnerabilities have their own private channel and must **never** be reported through public
issues or Discussions. See [SECURITY.md](./SECURITY.md) — we aim to acknowledge private reports within
a few business days.

## Contributing

If you would like to fix a bug or build a feature yourself, see [CONTRIBUTING.md](./CONTRIBUTING.md) for
the dev setup, the checks your change must pass, and the changeset requirement.
